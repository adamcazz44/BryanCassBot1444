# The SEO Harvest — theseoharvest.com

Static homepage for The SEO Harvest, a local-SEO lead-gen site for
Fort Worth, TX construction subcontractors.

- `index.html` — single self-contained homepage (inline CSS/JS/SVG, no build step).
- `CNAME` — custom domain binding (`theseoharvest.com`).
- `.nojekyll` — serve HTML verbatim.
- `.github/workflows/static.yml` — deploys the repo root to GitHub Pages on push to `main`.
